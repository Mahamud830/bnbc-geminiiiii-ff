# Installation Guide — BNBC ULTIMATE PRO v2.0

1. Extract `BNBC_Ultimate_Pro_Setup.exe` from the GitHub Actions Artifact ZIP and run it on Windows 10/11 (64-bit).
2. Open your structural model in **CSI ETABS 22**, then click **Detect & Connect ETABS 22** inside BNBC ULTIMATE PRO.
3. In Tab 5, optionally enable **Assign Wall Line Load** or **Assign Slab Loads** targeting your ETABS Group (e.g., `ALL`, `BEAMS`, `SLABS`), click **Preview Changes**, and click **Confirm & Push to ETABS 22**.
