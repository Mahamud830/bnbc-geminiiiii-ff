# User Manual — BNBC ULTIMATE PRO v2.0

1. **All 64 Districts:** Search or select any of Bangladesh's 64 districts in Tab 1. Always enter the Geotechnical Site Class (`SA`–`S2`) from your soil investigation report.
2. **Direct Beam & Slab Load Push:** Compute dead load and wall line load in Tab 3 (values automatically sync to Tab 5), select your target ETABS Group, preview, and push.
3. **PDF & Excel Export:** Use Tab 5 or Tab 6 to export `.pdf` engineering reports and `.xlsx` spreadsheets for foundation design and submission.
